# 线代知识网页（给女朋友的版本）

网址：`网址/xiandai/ta/`。恆 2026-11-09 定：给女朋友做一个和自己线代网页同样设计的网页，先放在线代网页下面。

## 和恆的线代网页的关系

- 页面框架 `index.html` 从 `xiandai/index.html`（2026-11-09 版）复制，功能完全相同：知识框架、知识点（线索自测）、题型卡（做完模式）、易错点、☆ △ ✓ ✗、今日、复习中心、错题区、搜索。
- 改了的地方：
  - 依赖用上一级的 `../依赖/`，不另存一份 KaTeX。
  - 本机记录键 `xiandai-ta-kb-v1`，和恆的 `xiandai-kb-v1` 分开，同一台设备上互不影响。
  - **不同步 GitHub**：`syncOn()` 永远返回 false，也不借用高数的令牌，记录只存在她的浏览器里（study-site 是公开仓库，记录不放进去）。换设备用页面「记录」里的复制、导入。
  - 目录按她的课件编号：第一章 1.2，第三章「矩阵的进一步讨论」3.1–3.3；没有章末考研页，目录里不显示章末入口。
- 以后改恆的 `xiandai/index.html` 不用同步这里，需要新功能时再单独搬。

## 内容来源和规则

- 资料是她的课件 PDF（恆 2026-11-09 上传的转换包）：1-2 初等变换与高斯消元、3-1 分块矩阵和初等矩阵、3-2 矩阵的秩（含手写批注版）、3-3 矩阵的逆，第三章同步练习 (1)(2)，练习册 p13–16 参考答案，自测题（一）参考答案。
- 页码写课件页码（「课件 第N页」）；批注版写「批注版 第N页」。
- 不放考研内容，题型卡不标 `level`（全部显示）。
- 数据格式、三色标记、线索规则和 `xiandai/说明.md` 相同。
- 发现的资料问题：课件 3-3 第13页练习 $B=(E+A)^{-1}(E-A)$ 里给的 $A$ 使 $E+A$ 不可逆，题目有误，没有收进网页。同步练习(2) 没有参考答案，网页里的答案是用代码算的。
